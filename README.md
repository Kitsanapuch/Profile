## Preview and release

`DevTutor` is the integration branch for Vercel previews. The live portfolio deploys from `main`.
Both English and Thai versions include Home, Experience, Activities, Projects, Skills, Certifications, Papers, and Contact. The About section is on Home.

Start a local preview from the repository root.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765/` for English or `http://127.0.0.1:8765/th/` for Thai. Each route has its own `index.html` file. The opening animation plays on a direct visit or refresh, and internal links use a short page transition.

The Contact page posts to the same-origin Vercel Function at `/api/contact`. To enable delivery to `kitsanapuch@gmail.com`, set `RESEND_API_KEY` and `CONTACT_FROM_EMAIL` in the Vercel Preview environment. The sender address must use a domain verified with Resend. Until those values are configured, the form reports that delivery is unavailable and shows direct email links. Do not put either value in browser code or Git.

### 🌱 Plant Nutrient Deficiency AI

An AI-powered system for diagnosing plant nutrient deficiencies from leaf characteristics.
